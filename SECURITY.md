# Security Policy

## Reporting a Vulnerability
If you discover a security issue in Portal‑OS, please open a private security report through GitHub’s security advisory system.

## Supported Modules
Security review applies to:
- Kernel runtime
- Identity physics
- Governance lawbook
- Routing topology
- Substrate adapters
- TEC economics
- SIM pipeline
- Umbrella lanes

## Non-Supported Modules
Domain suites (sports, XR, quantum, business) are experimental and not covered by security guarantees.

## Guidelines
- Never commit secrets.
- Never bypass Umbrella invariants.
- Never weaken identity physics constraints.
