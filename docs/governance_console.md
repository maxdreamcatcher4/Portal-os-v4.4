# Portal‑OS Governance Console v1

The Governance Console provides command, API, and UI access to Umbrella governance.

## Components

### GovernanceConsole
CLI-level governance interface.

### GovernanceCommands
Built-in commands:
- rules
- invariants
- escalate
- describe

### GovernanceApiServer
API-level governance interface.

### GovernanceDashboard
UI abstraction for governance snapshots.

### Integration
Works with:
- Umbrella Lawbook
- Kernel Services
- Routing
- Substrate
- SIM.MODE
- TEC
- Suites
