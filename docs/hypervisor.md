# Portal‑OS Hypervisor v1

The Hypervisor provides isolated execution zones, virtual kernels, and sandboxes.

## Components

### HypervisorZone
Isolated execution environment.

### VirtualKernel
Lightweight kernel instance inside a zone.

### HypervisorSandbox
Isolated execution for tasks or suites.

### HypervisorManager
Coordinates zones, kernels, and sandboxes.
