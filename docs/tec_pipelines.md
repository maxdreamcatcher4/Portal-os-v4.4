# Portal‑OS TEC Pipelines v1

TEC Pipelines provide structured, ordered execution for cognitive and system operations.

## Components

### TECStage
Atomic stage in a pipeline.

### TECPipeline
Ordered pipeline of stages.

### TECContext
Stateful pipeline context.

### TECEngine
Pipeline registry + executor.
