# Portal‑OS Architecture Overview

Portal‑OS v4 is structured into 11 major layers:

1. **Kernel** — planetary runtime, scheduler, invariants.
2. **Identity** — SIM identity physics, roles, auth, audit.
3. **Governance** — Umbrella lawbook, rules, policies.
4. **Routing** — planetary message topology.
5. **Substrate** — Class‑B and Class‑C compute substrate.
6. **TEC** — orchestration, accounting, economics.
7. **Suites** — domain OS modules (sports, XR, quantum, etc.).
8. **Shell** — UI, CLI, API.
9. **SIM** — cognitive architecture + deterministic build pipeline.
10. **Umbrella** — ecosystem lanes (PMD, Media, Law, Governance, Economics).
11. **Docs** — maps, diagrams, architecture references.

See `docs/roadmap.md` for upcoming work.
