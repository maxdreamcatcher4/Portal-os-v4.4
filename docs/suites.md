# Portal‑OS Suites v1

Suites provide modular, domain-specific functionality for Portal‑OS.

## Components

### SuiteManifest
Defines suite metadata and capabilities.

### Suite
Represents a loaded suite.

### SuiteRegistry
Stores and manages suites.

### SuiteEngine
Coordinates suite creation and loading.

- Identity Suite
