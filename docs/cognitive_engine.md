# Portal‑OS Cognitive Engine v1

The Cognitive Engine provides structured, domain-based cognition.

## Components

### CognitiveDomain
Named cognitive space (e.g., chess, city_systems, music_emotion).

### CognitiveFunction
Cognitive operation within a domain.

### CognitiveSession
Stateful cognitive context over time.

### CognitiveEngine
Registry, dispatcher, and session manager.

### Examples
- Chess domain
- City systems domain
- Music emotion domain
