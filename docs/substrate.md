# Portal‑OS Substrate v1

The Substrate is the deepest compute layer of Portal‑OS.

## Components

### SubstrateLayer
Atomic compute layer.

### SubstrateResource
Compute, memory, storage primitives.

### SubstrateGraph
Multi-layer topology.

### SubstrateEngine
Coordinates substrate initialization and activation.
