# Portal‑OS Orchestration Fabric v1

The Orchestration Fabric coordinates execution across Portal‑OS subsystems.

## Components

### OrchNode
Unit of work in the orchestration graph.

### OrchLink
Directed connection between nodes.

### OrchFlow
Ordered orchestration path.

### OrchFabric
Global orchestration graph.

### OrchEngine
Execution coordinator.
