# Portal‑OS Security Layer v1

The Security Layer provides identity, permissions, and policy evaluation.

## Components

### SecurityIdentity
Represents a security principal.

### SecurityPermission
Defines a capability unit.

### SecurityContext
Per-request security state.

### SecurityPolicyEngine
Evaluates permissions and policies.

### SecurityLayer
Top-level security façade.
